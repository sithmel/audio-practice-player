audio-practice-player demo

Add an MP3 file named sample.mp3 to this project folder (or update the src paths below) and reload. The player enhances MP3 <audio> and <video> elements by replacing native controls with practice controls (play/pause, full-track scrubber, A/B range markers with mm:ss, speed 10%–200% in ±10% steps, and repeat).
